# Fast Logic

[English](../README.md) · [Релизы](https://github.com/andrewmaiorov2010-source/Fast-Logic/releases) · [Сообщить об ошибке](https://github.com/andrewmaiorov2010-source/Fast-Logic/issues)

**Fast Logic** — Java-плагин для Mindustry 160.7, который меняет скорость выполнения инструкций стандартными процессорами Micro, Logic и Hyper.

## Возможности

- Независимые переключатели и множители скорости от **1× до 15×** для каждого из трёх процессоров.
- Общий переключатель ускорения для всех процессоров.
- Настройки сохраняются средствами Mindustry и остаются при обновлении мода.
- Подписи настроек на русском и английском языках.
- Длительность инструкции ожидания и игровое время не меняются.

По умолчанию для каждого процессора задан множитель 5×. Стандартная скорость — 2, 8 и 25 инструкций за тик для Micro, Logic и Hyper соответственно.

## Установка

### Встроенный браузер модов

Репозиторий уже включён в автоматический каталог Mindustry. Откройте **Моды → Браузер модов** и найдите **Fast Logic** или **логика**. Каталог обновляется автоматически раз в несколько часов.

### Установка JAR-файла

1. Откройте [последний релиз](https://github.com/andrewmaiorov2010-source/Fast-Logic/releases/latest) и скачайте `Fast-Logic-1.3.1.jar`.
2. В Mindustry выберите **Моды → Импорт мода → Импортировать файл**, укажите JAR и перезапустите игру.
3. Настройки находятся в разделе **Настройки → Fast Logic**.

При ручной замене старого JAR LogicSpeedFive удалите или замените только этот файл. Внутренний ID мода и ключи настроек `logicspeedfive.*` сохранены, поэтому множители и переключатели остаются прежними.

## Настройки

| Настройка | По умолчанию | Результат |
| --- | --- | --- |
| Общее ускорение | Включено | Включает или отключает ускорение процессоров |
| Micro Processor: переключатель и скорость | Включено, 5× | Множитель 1×–15×; базовая скорость 2 инструкции/тик |
| Logic Processor: переключатель и скорость | Включено, 5× | Множитель 1×–15×; базовая скорость 8 инструкций/тик |
| Hyper Processor: переключатель и скорость | Включено, 5× | Множитель 1×–15×; базовая скорость 25 инструкций/тик |

Отключение общего переключателя или отдельного процессора возвращает ему стандартную скорость. Значение 1× также соответствует стандартной скорости.

## Совместимость и проверки

- Целевая версия: **Mindustry 160.7**, байткод **Java 17**.
- Сохранены исходный внутренний ID `logic-speed-five`, Java-пакет и класс, а также ключи настроек.
- GitHub Actions компилирует плагин против официального JAR Mindustry 160.7 и выполняет отдельную проверку политики скорости без запуска игры.
- Мультиплеерная совместимость не заявляется.

Сборка и статическая проверка не заменяют проверку в игре. Для этой версии издатель не проводил игровую проверку.

## Сборка из исходников

Установите JDK 17 и получите официальный desktop JAR Mindustry 160.7. Запустите PowerShell:

```powershell
.\build.ps1 -MindustryJar 'C:\path\to\Mindustry.jar'
```

Скрипт создаёт `build/Fast-Logic-1.3.1.jar`. Он не запускает Mindustry и не включает игровые библиотеки в мод.
